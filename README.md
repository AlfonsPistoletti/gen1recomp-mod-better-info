This mod aims to give more information, while staying true to the gen 1 style.

## What does the mod change?
- **New Pokedex** 
    - with an expandable grid layout
    - 4-page DexEntry-screen showing base stats, learnset, evolutions, etc.
- **Summary Screen:**
    - New de-cluttered 3 to 4 page Stats screen with a dedicated page for moves
    - 4th page with DVs and Stat Exp is toggle-able in the mod options
    - Moves show their type, power, accuracy and PP
- **Battle Screen Moves** also show type, power, accuracy and PP
- Added a **Move Relearner** NPC to Celadon Mansion 2F

All toggleable in the mod options. Note: Options will only take effect after a restart.
The option "ADDIT. INFO" toggles if you can see DVs and Stat Exp.

## How to install
Download the .zip or modpkg and import it in the gen1recomp launcher.

Works with mods that add Steel, Dark and Fairy types.
Dex size should be variable, so the dex naturally works with mods that add more species.
